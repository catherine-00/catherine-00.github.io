프로젝트 개요

도로 주행 상황을 담은 영상 데이터를 AI가 분석하여, 실제 운전 중 발생할 수 있는 다양한 교통 시나리오를 텍스트로 설명하고, 이를 기반으로 퀴즈를 자동 생성하는 고령운전자를 위한 교통안전 교육 서비스입니다.

문제 상황

  • 고령 운전자 교통안전 교육 수요
  • 도로 상황 기반 퀴즈 자동 생성 필요

우리가 해결한 것

  • 영상→텍스트
  • RAG 기반 퀴즈

주요 기능

AI 기반 도로 상황 분석 및 퀴즈 생성 서비스

rAI 도로 주행 영상 분석
eNLP를 활용한 텍스트 변환
↻RAG 기반 퀴즈 생성
