프로젝트 개요

도로 주행 상황을 담은 영상 데이터를 AI가 분석하여, 실제 운전 중 발생할 수 있는 다양한 교통 시나리오를 텍스트로 설명하고, 이를 기반으로 퀴즈를 자동 생성하는 고령운전자를 위한 교통안전 교육 서비스입니다.

🚨 문제 상황

  • •고령운전자 교통사고 증가
  • •기존 교통안전 교육의 한계 (텍스트 중심)
  • •영상 기반 학습 콘텐츠 부족
  • •도로교통법과 실제 상황 연결의 어려움

🎯 우리가 해결한 것

  • ✓AI가 도로 영상 → 상황 설명 자동 생성
